High

And the interface displays progress and completion status

And the marker can continue reviewing and marking other responses

And processing does not automatically change original answers or confirmed marks.




Given background preparation is in progress

When the marker pauses and later resumes processing

Then completed results remain available

And processing continues for outstanding submissions without unnecessarily regenerating completed results.

	

Given an individual review fails or the local AI service becomes unavailable

When the system encounters the error

Then completed results are retained

And affected submissions or the paused queue are clearly identified

And retrying is possible when the problem is resolved

And manual marking remains available.

7A

	

As a user, I want to sign in with my assigned role so that I can access only the workspaces and actions I am authorised to use.

	

Given an active account has been assigned a role and workspace access

When the user signs in with valid credentials

Then the system opens the authorised workspace

And the available actions match the user’s assigned permissions.

	

Given the supplied credentials are invalid

When the user attempts to sign in

Then access is denied

And an error message is displayed without revealing whether a particular account exists.

	

High




7B

	

As a subject coordinator, I want to create workspaces and manage team membership so that tutors can access the exams they should mark.

	

 Given the coordinator has permission to manage workspaces

When the coordinator creates a workspace and adds an eligible tutor

Then the workspace is created with the supplied details

And the tutor appears in its member list with the assigned role

And the tutor can access the exams permitted by that membership.

Given a tutor belongs to a workspace

When the coordinator removes that tutor’s membership

Then the tutor can no longer access protected workspace data or submit changes

And previously recorded marking history remains available to authorised users.

	

Given the selected account is ineligible or already belongs to the workspace

When the coordinator attempts to add it

Then the system rejects the invalid or duplicate addition

And explains the issue without creating a duplicate membership.

	

High




7C

	

As a subject coordinator, I want to generate a time-limited, single-use password reset code for an authorised account so that its owner can regain access.

	

Given the coordinator is authorised to recover the selected account

When the coordinator generates a recovery code

Then the system displays the code and its expiry time And the account owner can use the valid code to set a new password

And the code becomes invalid after successful use.

	

Given a recovery code is incorrect, expired, already used, or belongs to another account

When a user submits it to reset a password

Then the reset is rejected And the existing password remains unchanged

And the user is informed that a valid recovery code is required.

Given a coordinator tries to generate recovery code for an account that does not belong to their workspace

When the coordinator generates password reset code

Then the reset is rejected And the reason is displayed

	

High




7D

	

As a user, I want to update my profile and avatar so that my identity is displayed consistently throughout the workspace.

	

Given the user is signed in

When the user saves valid profile changes

Then the updated details are saved And the user’s name and avatar are displayed consistently in the sidebar, account settings, and workspace member list

And the saved details remain available after signing in again.

	

Given the selected image is unsupported, exceeds the permitted size, or cannot be saved

When the user attempts to update the avatar

Then an explanatory error is displayed

And the previous saved avatar remains unchanged.

	

High




7E

	

As a tutor, I want submissions being marked by another tutor to be protected from conflicting edits so that our team can work simultaneously without overwriting each other’s decisions.

	

Given two authorised tutors are working in the same exam

When they mark different submissions simultaneously

Then both can save their decisions And each decision is stored against the correct submission without affecting the other tutor’s work.

Given a tutor opens a submission that’s already locked

When they click on the submission 

Then system notifies the user the submission is opened as a read only submission 

	

Given a tutor’s editing lock has expired or the submission has changed since it was opened

When the tutor attempts to save an outdated decision

Then the system rejects the conflicting update And the latest saved decision remains unchanged

And the tutor is asked to reload or reacquire access before continuing.

8A

	

As a subject coordinator, I want to create an exam with an optional rubric document so that I can prepare the exam before all marking materials are ready.




	

Given the coordinator has selected an authorised workspace

When the coordinator enters a valid exam name and creates the exam without uploading a rubric

Then the exam is created in that workspace

And it appears in the exam list

And the coordinator can upload its answers and rubric later.

	

Given the exam name is empty or invalid

When the coordinator attempts to create the exam

Then creation is rejected

And the relevant field is identified

And the entered information remains available for correction.

	

High




8B

	

As a subject coordinator, I want to assign a type to each question so that tutors are shown the appropriate marking tools.

	

Given an exam contains imported questions

When the coordinator assigns a supported type and saves the configuration

Then the selected type is displayed for that question

And the marking interface provides the tools configured for that type.

	

Given an unsupported type is submitted or the configuration cannot be saved

When the coordinator attempts to apply the change

Then the change is rejected

And the previous saved classification remains active

And an error message is displayed.

	

High




8C

	

As a subject coordinator, I want to upload or replace a PDF or DOCX rubric document for an exam so that the marking team can use the appropriate reference material.

	

Given an exam exists and the coordinator selects a valid PDF or DOCX file within the permitted size limit

When the coordinator confirms the upload

Then the document is associated with the selected exam

And its filename and available viewing or download controls are displayed.

	

Given the file is unsupported, unreadable, too large, or cannot be uploaded

When the coordinator attempts the upload

Then the upload is rejected with an explanatory message

And the previously saved document and marking data remain unchanged.

	

High




8D

	

As a subject coordinator, I want to generate an editable rubric draft from a document that follows the supported template so that I can prepare question rubrics without entering every option manually.

	

Given a supported rubric document contains identifiable questions, scores, and descriptions

When the coordinator selects automatic rubric generation

Then the system creates a draft containing the recognised question rubrics

And each score option includes its score and description

And the coordinator can inspect, correct, and confirm the draft before it becomes active.

	

Given some document sections can be recognised but others cannot

When generation completes

Then recognised sections are presented as a draft

And unrecognised or ambiguous sections are identified for manual review

And the coordinator can complete the missing information manually.




Given the document cannot be parsed or does not follow the supported structure

When the coordinator requests automatic generation

Then the system explains that a usable draft could not be generated

And existing active rubrics and confirmed marks remain unchanged

And manual rubric editing remains available.

	

High




8E

	

As a subject coordinator, I want to add, edit, and remove score options for each question so that the rubric reflects the intended marking criteria.

	

Given the coordinator has selected a question

When the coordinator edits its score options and confirms valid changes

Then the updated rubric is saved for that question

And every option contains a score and description

And the tutor can use the updated options during marking.




Given multiple descriptions belong to the same score level

When the rubric options are prepared for display

Then that score level is presented as one selectable option

And its associated descriptions are retained within that option.

	

Given an option is linked to previously confirmed marks

When the coordinator attempts to remove it

Then the affected records are identified

And the system prevents silent deletion of their scoring association

And the coordinator must resolve those records through the agreed reassignment or review process before completing the removal.

	







8F

	

As a subject coordinator, I want confirmed changes to a rubric option’s score to update all linked marks so that previously marked responses remain consistent with the revised rubric.




	

Given a rubric option has been used to mark student responses

When the coordinator changes its score

Then the system previews the affected responses and their proposed score changes

And when the coordinator confirms the update, all marks linked to that option are updated

And affected totals and result summaries are recalculated

And the previous and updated values, coordinator identity, and timestamp are recorded.

	

Given a save failure or conflicting update occurs

When the coordinator confirms the score change

Then the operation is not reported as successful

And the system does not leave the rubric and linked marks in a partially updated state

And the coordinator receives an explanation and a recovery or retry option.
